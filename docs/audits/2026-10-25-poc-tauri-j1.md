## A-Strict

- `withGlobalTauri = false`.
- Aucun fichier `capabilities/`, aucun plugin, aucun `invoke_handler`.
- `create = false` : fenêtre construite dans `setup` pour appliquer
  `invoke_system` et `initialization_script`.
- `dragDropEnabled = false`, `devtools = false`, `freezePrototype = true`,
  `csp = null` (CSP serveur autoritaire), `assetProtocol` désactivé.
- `invoke_system` remplace `ipc-protocol.js` par un stub qui lève
  `IPC Tauri désactivé (A-Strict)`.
- wry expose aussi un transport brut `window.ipc` (objet gelé) et
  `window.webkit.messageHandlers.ipc` ; `A_STRICT_SCRUB` remplace le
  `postMessage` du handler natif par un stub qui lève
  `IPC natif désactivé (A-Strict)`.
- Garde-fou `build.rs` : un fichier dans `capabilities/` fait échouer le build.

## Limites et suites

- Le namespace `__TAURI_INTERNALS__` reste injecté ; le callback WebKit
  `evaluate_javascript` est prévu pour le MVP si le token brut doit venir
  exclusivement du DOM.
- `rodio` et le tray D-Bus sont prévus au J4 ; `notify-rust` est déjà implémenté
  mais désactivé par défaut.
- Le CLI Tauri n'est pas installé ; packaging `.deb` au J5.
- La baseline Firefox fraîche et les 5 runs STEP2/VRAM sont au J3.
- `cargo test --workspace` exige désormais les en-têtes WebKit et Rust 1.90 ;
  `cargo test` reste limité au pipeline via `default-members`.
