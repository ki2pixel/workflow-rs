## Décision

**Tauri A-Strict conservé pour le MVP.** Le `.deb`, l'extraction sans root,
les deux modes de supervision et l'invariant « GUI jamais parent » sont
validés. Le client reste un client HTTP ; le serveur est supervisé
indépendamment. Le point de vigilance du soak J4 (`WebKitNetworkProcess` et
polling du frontend legacy) reste à traiter au MVP, sans remettre en cause le
choix Tauri.

## Limites

- L'installation via `sudo apt install` n'a pas été exécutée (root non
  utilisé) ; seule l'extraction sans root et l'exécution du binaire extrait
  sont validées.
- Aucun run STEP2/STEP8 sous l'unité systemd : le test porte sur un serveur
  de test `:5005`. `ProtectSystem=full` est conservé et `ProtectHome` est
  désactivé pour ne pas bloquer les caches CUDA/EffectCraft ; cette
  combinaison devra être rejouée avec une étape réelle au MVP.
- Le `.deb` ne contient que le client ; le serveur, les modèles et les
  dépendances CUDA/TPU restent dans le dépôt.
- L'audio hôte n'embarque pas les MP3 ; `--audio` exige `--sound-dir`.
- Le single-instance reste différé au MVP.
- Le binaire strippé conserve des chaînes de compilation `.cargo/registry`
  dans les messages de panique ; aucun secret ni chemin de production.
- La production n'a pas été démarrée : l'unité de production n'est pas
  installée et `--start` n'a été utilisé qu'avec la config de test `:5005`.
