## 7. Limites

- Époque 5 sélectionnée sur D-060, qui sert aussi à l'évaluation : rappel
  D-060 optimiste.
- Open-set composité sur les mêmes fonds M6 : biais de domaine résiduel.
- Négatifs synthétiques plus difficiles que D-060 (12–13 % de FP à 0,30).
- AP small 0,22–0,26 : les logos de 100–200 px restent fragiles en plein
  cadre 416 ; piste ROI en B2.
- Localisation A2 : présence 96,7 %, boîte `gt_logo` 91,7 %, rappel connu
  combiné 94,6 % ; suffisant pour la revue, pas pour un `apply`.
- Mono-classe, pas de séparation logo/bandeau/texte ni de persistance.
- Pas de FP16/INT8 fine-tuné.
- Précision non pénalisée pour les doublons appariés.

## 9. Reproduction

```sh
B1=/media/kidpixel/WORK/.../references_logos/training_yolo_b1
PY=/mnt/venv_ext4/audio_env/bin/python

# entraînement (environnement labo)
cd "$B1/code/YOLOX"
PYTHONPATH="$PWD:$B1/pydeps" "$PY" tools/train.py \
  -f exps/example/custom/logo_b1.py -d 1 -b 12 \
  --ckpt "$B1/weights/yolox_nano.pth"

# export (necessite un checkpoint .pth ; celui de l'epoque 5 n'a pas ete
# conserve, seul l'ONNX fige reste la reference)
EP5_CKPT=/chemin/vers/checkpoint_ep5.pth
PYTHONPATH="$B1/code/YOLOX:$B1/pydeps" "$PY" "$B1/scripts/export_b1.py" \
  --ckpt "$EP5_CKPT" \
  --output "$B1/exports/logo_b1_nano416.onnx" --size 416

# bench metriques (toutes les detections, seuil bas)
cargo run --release -p workflow-steps --example yolo_bench -- \
  --model "$B1/exports/logo_b1_nano416.onnx" \
  --frames "$B1/dataset/eval_d060/frames.json" \
  --kind yolox --classes 1 --size 416 --device cuda \
  --onnxruntime /mnt/venv_ext4/transnet_cv5_env/lib/python3.10/site-packages/onnxruntime/capi/libonnxruntime.so.1.23.2 \
  --warmup 1 --iters 1 --conf 0.001 --iou 0.65 \
  --output "$B1/dataset/eval_d060/bench_final_iou65.json"

# latence au point de fonctionnement
cargo run --release -p workflow-steps --example yolo_bench -- \
  --model "$B1/exports/logo_b1_nano416.onnx" \
  --frames "$B1/dataset/eval_d060/frames.json" \
  --kind yolox --classes 1 --size 416 --device cuda \
  --onnxruntime /mnt/venv_ext4/transnet_cv5_env/lib/python3.10/site-packages/onnxruntime/capi/libonnxruntime.so.1.23.2 \
  --warmup 20 --iters 100 --conf 0.30 --iou 0.65 --limit 20 \
  --output "$B1/dataset/eval_d060/latency_final.json"

# évaluations
"$PY" "$B1/scripts/eval_d060.py" --bench ... --gt ... --output ...
PYTHONPATH="$B1/pydeps" "$PY" "$B1/scripts/eval_b1.py" \
  --onnx "$B1/exports/logo_b1_nano416.onnx" \
  --annotations "$B1/dataset/annotations/instances_test_open2017.json" \
  --images-dir "$B1/dataset/test_open2017" --output ...
```

Le checkpoint d'époque 5 n'est conservé qu'en ONNX ; les poids et le dataset
restent hors dépôt et ne sont pas redistribués.
